# 组件交接：全页视觉收敛与九环重做

给接手 `src/components/dashboard/` 的同学。看完这份就能开工，不需要读懂地图和路由那一套。

**范围**：只改 `src/components/dashboard/` 下的组件、`src/index.css`、`index.html`。
**不要动**：`src/components/CityMap.tsx`、`src/App.tsx`、`src/engine/`、`src/pages/`、`docs/接口契约.md`、`docs/数据边界.md`。这几个文件同期有人在改渲染架构，碰了会冲突。

视觉权威是 `docs/design/主看板定稿-规格.md` 和 `docs/decisions/2026-08-17-视觉改浅色.md`。
`docs/视觉方案.md` 已作废，别看。

---

## 一、先理解要解决什么

当前实现能跑，问题是视觉没有系统。三件事最伤：

1. **字号全线过小**。全仓 116 处任意字号里 97 处 ≤10px，其中 8px 有 28 处、7px 有 3 处，12px 只有 2 处。九环的环名是 7px，事件卡的标签是 7px。
2. **紫色滥用**。`#5B5BD6` 本该只标"当前选中"和"主行动"，现在散在十几个 pill 和底色方块上，注意力被摊平。
3. **九环读不出来**。九个 16px 圆点横排挤在 226px 宽的右栏里，配 7px 文字。九环是这个产品的核心叙事，现在是最不可读的一块。

目标是类 Uber 的克制浅色调度台。地图是第一视觉主体，左右栏服从地图。
**不要**改成深色数字孪生、泛紫 SaaS 模板、重渐变、玻璃拟态或大量悬浮卡片。

## 二、设计 token

先在 `src/index.css` 里定义，然后逐个组件替换掉硬编码的十六进制值。

| token | 值 | 硬约束 |
|---|---|---|
| `--surface-page` | `#F4F5FA` | 最外层底色 |
| `--surface-card` | `#FFFFFF` | 面板、统计卡 |
| `--surface-sunken` | `#F7F8FB` | 输入框、空态底 |
| `--line-hairline` | `#EDEFF4` | 栏内分隔线 |
| `--line-border` | `#E8EAF0` | 卡片边框 |
| `--ink-1` | `#1A1D26` | 标题、统计数字 |
| `--ink-2` | `#5B6072` | 正文、说明 |
| `--ink-3` | `#99A0AE` | 时间戳、单位 |
| `--accent` | `#5B5BD6` | **全页实心出现不超过 3 处** |
| `--accent-weak` | `#EEEEFB` | 主色浅底 |
| `--status-fire` | `#E5484D` | 火情、封路 |
| `--status-go` | `#30A46C` | 正常、推荐路线 |
| `--status-water` | `#3B82F6` | 水源点 |

**三条底线**

- 面只有三层（page / card / sunken），不许有第四层。
- 描边只有两档（hairline / border），不许有第三档。
- 阴影只有两档：面板 `0 1px 3px rgb(16 24 40 / .06), 0 1px 2px rgb(16 24 40 / .04)`，地图浮层 `0 8px 24px rgb(16 24 40 / .12)`。不许有第三档，不许用重投影。

**accent 的三处配额**：顶栏「首页」激活态、事件卡「处置」按钮、左栏图层勾选框。除此之外一律用 ink 灰阶。现在的紫色 pill、紫色底方块、紫色计数徽章全部去掉。

## 三、字体层级

删掉 7px、8px、9px 三档，97 处要改。

| 名 | 尺寸 / 字重 | 用途 |
|---|---|---|
| Display | 20px / 600，mono tabular | 统计卡数字 |
| Title | 15px / 600 | 顶栏平台名 |
| Section | 13px / 600 | 面板标题、方案标题、事件卡标题 |
| Body | **12px** / 400 | 正文、说明、方案理由。**正文下限** |
| Label | **11px** / 500 | 标签、tab、图例、九环环名。**辅助文字下限** |
| Footnote | 10px / 400 | 只给时间戳、OSM 许可证、OSM way id。**唯一例外** |

判断规则：拿不准就往上取一档。除了 Footnote 那三类，页面上不应该再出现 10px 以下的字。

## 四、逐组件改动清单

### `TopNav.tsx`

- 导航项 12px 保持，图标 14px 保持。
- **1180px 断点**：现在 nav 的 `scrollWidth` 是 478、`clientWidth` 是 339，**139px 被裁掉**，后两个导航项看不见。加一个 1280px 断点，窄屏时把「复盘评估 / 系统管理」收进「更多」下拉，或者只留图标。这是硬性验收项。
- 搜索框、天气、时钟保持。时钟已经是 `tabular-nums`，别动。
- `DEMO · 非生产` 标识**必须保留**，样式可调，内容和显眼程度不能降。

### `LeftRail.tsx`

- 整栏静默：除了图层勾选框用 accent，其余全部 ink 灰阶。
- 资源行：名称 Label 11px，数字右对齐用 mono tabular，数字用 ink-1。
- 底部那句"图层开关为界面状态。实时气象、路况与摄像头数据未接入。"**必须保留**，这是真实性边界声明。字号提到 Footnote 10px。

### `StatBar.tsx`

- **删掉六个 `#EEEEFB` 紫底圆角方块**。图标改 16px 单色 ink-3，直接放标题左边。
- 标题 Section 13px，指标名 Label 11px，数值 Display 20px mono。
- 卡片内边距收紧，让三组数字横向扫描更快。
- 右上角的来源角标（`OriginMark`）保留，这是真实性边界的一部分。

### `ChainRail.tsx` — 改动最大的一块

现在是九个圆点横排。**改成纵向轨道**，右栏本来就是竖的。

```
每行 32px 高：
  左侧 20px 状态图钉 + 上下连接竖线
  右侧 环名 Label 11px + 状态文字 Footnote 10px
  当前环：整行 accent-weak 底 + 左边缘 2px accent 竖条
```

九行 × 32px = 288px，右栏放得下，进入时滚动到当前环。

**图钉用形状编码，不能只靠颜色**（这是 `docs/decisions/2026-08-17-视觉改浅色.md` 明确保留的一条）：

| 状态 | 形状 | 颜色 |
|---|---|---|
| 已完成 | 圆形实心 + 白勾 | `--status-go` |
| 有摘要 | 圆形空心 | `--accent` |
| 当前环 | 圆形实心 + 序号 | `--accent` |
| 需人工拍板 | **方形** | `--accent` |
| 未执行 | 圆形空心 | `--ink-3` |
| Phase 1 不做 | 圆形虚线边 | `--ink-3` |

「需人工拍板」用方形是关键：人工门禁是这个产品的卖点，必须一眼能从其他环里挑出来。现有的 `states` 数据结构不用改，只是渲染层多认一个门禁标记。

### `RightPanel.tsx` + `StepPanels.tsx`

- **列表态和详情态统一到同一套卡片**。现在两边的圆角、内边距、标签样式各写各的。抽一个 `<EventCard>` 和一个 `<Field label value>`，两处都用。
- 筛选 tab 从 8px 提到 Label 11px，激活态用 accent-weak 底 + accent 字。
- 事件卡：标题 Section 13px，副标题 Body 12px，时间戳 Footnote 10px。火情展开态整卡淡红底 `#FDF0F0` 保留。
- 「查看下一环」按钮现在是近黑 `#1A1D26`，**改回 accent 实心**。
- `StepPanels.tsx` 有 53 处 ≤10px，是重灾区，按字体层级逐条过。

### `Provenance.tsx`

**改样式可以，改语义不行。** `OriginMark` 的三态（公开数据实心圆 / 估算数据半填充圆 / 模拟数据空心圆）和 `ConfidenceMark` 的形状编码是产品的真实性边界，形状区分必须保留，只允许调尺寸和字号（提到 Label 11px）。

### `index.html` + `index.css`

- `index.html` 现在还是 `<html lang="zh-CN" class="dark">`，顶上注释还指向已作废的 `docs/视觉方案.md`。**删掉 `class="dark"` 和那行注释**。
- `index.css` 里的 `.dark { ... }` 整块删掉。
- `src/components/ui/button.tsx` 里成套的 `dark:` 变体一并清掉。

## 五、验收标准

在 **1440×900** 和 **1180×800** 两个视口各过一遍：

- [ ] 全页搜不到 `text-[7px]`、`text-[8px]`、`text-[9px]`
- [ ] 10px 只出现在时间戳、OSM 许可证、way id 三类地方
- [ ] accent 实心出现不超过 3 处
- [ ] 面 3 层、描边 2 档、阴影 2 档，没有第四/第三档
- [ ] 1180px 下顶栏导航项**一个都不丢**（现在丢 2 个）
- [ ] 两个视口都无横向滚动
- [ ] 九环能一眼看出当前环、已完成环、待执行环，人工门禁环形状与其他环不同
- [ ] 事件列表态与详情态的卡片来自同一套组件
- [ ] `DEMO · 非生产`、来源角标、图层未接入声明三处真实性边界原样还在
- [ ] 键盘 Tab 能走完所有可操作控件，焦点圈可见
- [ ] `npm run build` 通过（`tsc -b` 无类型错误）
