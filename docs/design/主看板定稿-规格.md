# 主看板定稿规格

从 8/17 定稿截图量出来的实施与验收基准。**定稿 PNG 待归档为 `主看板定稿-20260817.png`**，在它到位之前本文件是唯一可比对的基准。

**验收视口 1440 × 900**，比对时用 `resize_window` 固定后逐项过。

## 三、逐区规格

### 顶栏

左起：标题「广州市应急管理局综合指挥平台」15px/600；六个导航项「首页 / 态势总览 / 事件处置 / 资源调度 / 复盘评估 / 系统管理」13px，各带一个 14px 图标，**首页为激活态**（主色弱底 + 主色字 + 圆角 8）；居中偏右一个搜索框（宽约 270，圆角 8，浅底无边框）；右起「24°C」「2026/8/17 20:55:46」等宽数字、「指挥长」带头像 chip。

### 左栏，两个可折叠区块

**可用资源**。标题行带折叠箭头。下面一排三个 tab「消防 / 公安 / 医疗」，**医疗为激活态**（主色底白字，圆角 8）。tab 下是资源行，每行左侧一个圆形图标 + 名称，右侧数字，最右一个方形复选框。定稿医疗页四行：120 网络医院 148、救护车 312、非 120 网络医院 188、社区医院 167。

**图层控制**。标题行带折叠箭头。四行开关：气象雷达、道路路况、推荐路线、摄像头数据，**四个全部勾选**，勾选框是主色实心带白勾，圆角 4。

### 地图区

顶部一排五个 tab，定稿是 `XXX / XX / XX / XX / XX` 占位，**实施时换成场景切换**（四个场景名）。

地图内元素：楼栋标记、资源点位图标、编号圆圈、绿色实线（推荐路线）、红色虚线（道路封堵）、事发楼栋高亮。

**要素弹出卡**（定稿示例「中山二路 106 号」）：白底圆角 12，标题 + 火情标签 + 关闭叉；四行状态，左标签右值，值前带一个 6px 圆点表示状态色；末行「更新时间」等宽数字，与上面用分隔线隔开；底部一个展开箭头。

**图例**固定在右下，四行：推荐路线（消防车）绿实线、道路封堵（云梯车禁行）红实线、交通管制点绿圆点、水源点蓝圆点。

**地图控件**右下竖排：定位、`2D` 切换、放大、缩小，各 32×32 白底圆角。

### 右栏，事件

标题行「事件」带折叠箭头。下面筛选 tab 两行：全部 / 火情 / 警情 / 重大事件 / 其他，**全部为激活态**（主色弱底主色字）。

事件卡两态：

**展开态**（定稿第一张）整卡淡红底，标题两行 + 右上角两个标签（类型 + 状态）；副标题灰字（建筑类型、层数高度）；更新时间；分隔线；「报警信息」小节，四行左标签右值，**报警电话用火情色**；底部两个按钮，「派遣」主色实心，「查看」白底描边，等宽各占一半。

**收起态**（其余三张）白底，标题 + 两个标签 + 副标题 + 更新时间。

### 底部统计条

六张等宽卡片，间距 10。每张：左上一个 20px 圆角图标 + 标题（119 消防 / 110 公安 / 120 急救 / 交警开路 / 无人机 / 水源）；下方三组数字横排，上标签 11px 灰、下数值 22px/600 深色等宽。

**定稿写的是「120 急数」，是错字，实施用「120 急救」。**

## 五、定稿没画、但必须加的

定稿只覆盖主看板一屏，产品的核心内容不在里面。以下按计划补，不算偏离定稿：

- **九环轨道**，进入事件详情后出现在右栏顶部
- **方案 A/B 对比**，Strategy 环
- **封路交互与重算结果**，地图上被封路显红虚线，右栏列已封清单
- **数据来源角标**，模拟值后一个空心小圆、估算值后一个半填充小圆，悬停出处
- **不可达提示**，封死终点时的降级态与撤销入口
