# 验收清单

> 判断某个模块"做完了"的客观标准。没有标准就会永远在改。

---

## 黄金路径（最高优先级）

这是评审现场唯一会被完整看到的东西。**如果只能保证一件事跑通，保这条。**

```
00:00  打开主看板 —— 城市底图 + 当前态势（不是指标海）
00:20  一条火情警单进来 —— 「态势补齐」过程可见
00:50  生成 Fire Event —— 已确认事实 / 待核实信息 分开展示
01:20  生成响应方案 A/B/C —— 地图上同时呈现，差异用颜色标出
02:00  【关键】评委现场改一个条件 —— 系统当场重算
02:30  人工确认方案 —— 生成协同任务清单
02:50  执行反馈 + 偏差记录
```

- [ ] 全程无卡顿、无报错
- [ ] **02:00 那一步能真的重算**（这一步证明不是录像）
- [ ] 彩排 ≥3 次
- [ ] 有离线可运行版本
- [ ] 有完整录屏备份

---

## 火情模块（119）

- [ ] 能从一条模拟警单走到生成 ≥2 个响应方案
- [ ] 每个方案显示：预计到场时间（**带误差带**）、需要协同的部门、执行后的资源覆盖变化
- [ ] 方案对比有明确差异说明（不是两张长得一样的卡片）
- [ ] 两方案差值落在误差带内时，明确显示「无显著差异」
- [ ] 有一步人工确认，确认后生成任务清单
- [ ] `approvalLevel: 'human'` 的动作**不能**被自动执行
- [ ] 所有模拟数据在界面上有标注
- [ ] 改变任意输入条件（如某条路封闭）能重算并刷新
- [ ] 「请求开路」动作能显示：哪几个路口、各省多少秒

- [ ] 首屏 3 秒内加载完成
