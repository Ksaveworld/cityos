# 导航与多场景地图真实性收口

**日期**：2026-08-19

**状态**：已确认，进入实现

**基线**：`fix/perf-render@48afa91`

**影响**：`src/App.tsx`、`src/components/CityMap.tsx`、`src/components/dashboard/`

**不影响**：`src/engine/`、`src/agent/`、`docs/接口契约.md`、外部 API、依赖

## 本轮直接需求

1. 顶栏不再保留无行为的视觉壳；平台标识返回全局看板，可见导航必须切换到既有能力。
2. 左栏地图图层开关必须真实改变地图内容，不能只更新组件内部勾选状态。
3. 荔湾火情、日常高层火情、刑民警情、交通协同、重大布防都要有可辨认的场景地图，不再显示空白网格和“未执行地图计算”的中央占位卡。
4. 组件与场景入口保留；110 与重大布防仍是明确标注的前端模拟展示，不扩展真实求解、真实接口或自动控制。
5. 参考 `ui展示.pdf` 与 `Emergency Dispatch UI_UX Design.make` 的布局和卡片层级，但不把资产中的硬编码数据、假连接状态、传感器、视频控制、AI 对话或移动端能力当成需求。

## 视觉冻结

- 保留当前类 Uber 的浅色体系：页面底 `#F4F5FA`、白卡、极浅描边、`#5B5BD6` 主色；红、绿、蓝只承担告警、可行与资源语义。
- 保留顶栏、地图主画布、右侧工作台与底部摘要的总体结构，不整体移植参考稿。
- 唯一新增的视觉记忆点是“同一指挥画布随场景变形”：
  - 日常火情：高层楼栋、18 层事件点、三类模拟 Signal 与资源响应；
  - 刑民警情：事件点、辖区边界、响应范围与附近公安资源；
  - 交通协同：事故路段、关键路口、绕行线与协同资源；
  - 重大布防：场馆范围、出入口、分区、集结区与部署点。
- 非荔湾场景使用前端态势示意图，必须持续显示“模拟展示”；不得伪装成 MapLibre 路由或引擎计算结果。

## 导航行为

| 入口 | 行为 |
|---|---|
| 平台标识 | 回到态势总览，不静默清空封路、方案或人工确认 |
| 态势总览 | 当前三栏地图总览、事件摘要和底部统计 |
| 事件处置 | 打开事件列表；选中事件后进入既有九环 |
| 资源调度 | 进入资源聚焦布局并打开既有公开资源参考；模拟资源只读、不真实下发 |
| 复盘评估 | 切到“5·16 公开复盘”并进入 Review 建议报告 |

独立“首页”和“系统管理”暂不显示。没有真实行为的搜索、通知和账户下拉不继续伪装成按钮。

## 地图控制行为

左栏四个开关保留，但改为受 `App` 控制并传入地图：

- 气象雷达：显示或隐藏明确标注为模拟的气象影响层；
- 道路路况：显示或隐藏模拟路况着色；
- 推荐路线：显示或隐藏候选路线/协同走廊；
- 上游视频点位：显示或隐藏模拟上游点位，只表达输入位置，不做识别或分析。

资源列表继续展示现有模拟快照；不再保留无地图效果的逐行复选框。公开消防站、医院位置与模拟资源状态必须使用不同来源说明。

## 场景内容边界

- 荔湾 5·16：继续使用真实公开底图、路网和地址锚点；路线、资源状态与处置过程按既有来源标注。
- 日常高层火情：整条链路是基于公开演练参数构造的模拟展示，不复用 5·16 路线、ETA、封路或资源状态。
- 刑民警情、交通协同、重大布防：补齐九环的模拟摘要和场景化地图；视觉上成立，但不声称真实警务、交管、客流或跨部门系统已经接入。
- 高风险动作始终保留人工门禁；不新增自动道路控制、无人机控制、传感器监控或真实任务下发。

## 验收

1. `npm run typecheck`、`npm run lint`、`npm run build` 通过，SelfTest 保持 43/43。
2. 在 1440×900 和 1180×800 下验证五个导航行为、五种地图状态与四个图层开关。
3. 每个场景地图具有不同的事件、区域、路线/走廊和资源表达；不出现空白占位卡。
4. 每个可见按钮产生明确状态变化；console 与 pageerror 为零，无横向滚动。
5. 公开复盘与日常模拟往返不串数据；地图切换和导航切换不破坏荔湾封路、重算、撤销和离线回退。
6. 停在本地可评审候选；不推送 `main`，不部署。
