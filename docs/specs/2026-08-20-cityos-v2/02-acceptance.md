## B. 日常响应

### AC-ROUTINE-01 双入口收敛

```gherkin
Given 用户在总览或事件处理入口
When 触发“模拟事件流注入”或提交工作人员手工输入
Then 两种入口都产生标有“模拟事件 / 未接真实源”的同类事件上下文
And 事件 ID、方案版本、人工批准和任务状态只存在一份
```

### AC-ROUTINE-02 手工输入范围

```gherkin
Given 工作人员打开手工输入
When 选择演示模板
Then 事件类型、地点、时间、等级、来源、天气、道路状态被预填且可在受限范围内编辑
And 补充描述可自由填写但显示为线索/待核实信息
When 缺少必填字段或输入超出模板约束
Then 不能开始研判，并显示可理解的修正提示
```

### AC-ROUTINE-03 事件建立与 Brief

```gherkin
Given 输入通过校验
When 工作人员点击“开始研判”
Then 页面显示地址标准化、事件编号、来源标签和研判中状态
And 显示六块 AI Brief：核心态势结论、事件事实与证据、风险研判与优先级、态势趋势预测、周边资源与现实约束、关键信息缺口
And 每一块至少包含 3 条带来源、确认状态和真实/模拟/估算/未知标签的有效信息
And 任一块信息不足时，不允许进入方案审批
```

### AC-PLAN-01 方案与人工门禁

```gherkin
Given 六块 AI Brief 完整
When 系统生成候选方案
Then 至少显示 A 和 B 两个包含资源、路线、时间窗、任务顺序、风险和降级条件的完整方案
When 尚未人工批准
Then 不得生成有效任务包或执行模拟送达
When 人工否决方案
Then 返回候选方案阶段，并显示重新生成入口
```

### AC-DELIVERY-01 受控重试与重批准

```gherkin
Given 方案 v1 已获人工批准并生成负责人任务包
When 一次模拟送达出现异常
Then 原异常记录保留，且系统不自动重试
When 工作人员调整车辆数量、资源点或负责人
Then 展示重算后的 ETA/覆盖风险摘要或诚实的“ETA 未变化/模型不适用”说明
And v1 批准、任务包和送达资格立即标为失效
And 在 v2 再次人工批准前，不得送达或重试
When v2 已再次人工批准
Then 允许一次受控重试
And 第二次重试按钮不可用或明确提示达到演示上限
```

### AC-DELIVERY-02 状态可见性

```gherkin
Given 已生成任务包
When 用户查看送达区域
Then 能看到待生成、待发送、已送达、已签收、执行中、已完成/异常的当前状态
And 每项显示接收人、角色/部门、时间、内容摘要和模拟属性
And 未送达项目不能被模拟签收
```

### AC-RECORD-01

```gherkin
Given 日常响应完成主要演示
When 用户查看日常记录
Then 能追溯输入、Brief、方案版本、批准、任务包、送达、异常、一次重试和签收
And 记录明确是模拟演示记录，不声称真实处置结果
```

### AC-HISTORY-01 事实边界

```gherkin
Given 用户进入 5·16 公开复盘
When 查看历史事实与基线区
Then 官方公开锚点、来源和未知项被分别展示
And 缺失的原处置路线、车辆、路口协同、签收等以“公众信息约束下的基线处置模拟”补足并显示来源边界
And CityOS 模拟车辆、ETA、资源和任务不会被写成真实历史还原
```

### AC-HISTORY-02 动态舞台

```gherkin
Given CityOS 模拟方案已获人工批准
When 用户进入独立动态舞台并开始播放
Then 可看到街区地图、事件高亮、模拟车辆、路线推进、路况/绕行、关键节点、任务状态和时间线变化
And 所有非公开事实均清楚标为模拟或估算
When 用户暂停并重放
Then 舞台可重复运行，且不改变方案、批准或日常链状态
And 地图、车辆、任务卡与时间线由同一个播放进度同步变化
And reduced-motion 环境改为离散阶段切换而不是逐帧动画
```

### AC-HISTORY-03 对比与知识沉淀

```gherkin
Given 动态舞台结束
When 用户查看对比报告
Then 对比区分别呈现公开事实、公众信息约束下的基线处置模拟与 CityOS 方案模拟
And 报告说明假设、ETA/资源估算、受阻点、成本、未解决风险和推演边界
And 不使用“证明真实更优”或“历史还原完成”表述
When 用户选择沉淀知识
Then 可见案例草稿和来源信息
And 若没有知识库后端，明确标“演示草稿 / 未写入知识库”
```
