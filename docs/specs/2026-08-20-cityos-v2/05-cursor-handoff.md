## 最容易被写错的六处

每批开头贴给它，比事后返工便宜：

1. **不写无来源的精确时刻**（D-22）。110 场景只有日期、8:20 发现、9 人受伤、封锁解除是公开锚点，其余一律 `T+` 相对时间。缺口处写"未公开"，不许编"8:23 首车到场"。
2. **不出现涉案人员身份、籍贯信息**（REQ-HISTORY-03）。公开报道里有，产品里不要。
3. **已确认与待核实必须用不同形状编码**，不能只靠颜色。这是 `CLAUDE.md` 的既有规则。
4. **不写"证明真实更优""历史还原"**。对比一律表述为"同一假设集下的模拟对比"。
5. **逐帧动画不许走 React state**。用 `useRef` + `rAF` + 命令式 API，否则整页重渲染。`App.tsx:77` 有踩过坑的注释。
6. **模拟数据必须有标注**，但标注不能重复到失效——一屏里同一口径挂一个角标就够。
