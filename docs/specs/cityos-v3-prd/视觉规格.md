# CityOS v3 视觉规格

> 状态：**唯一视觉权威**。与 `PRD.md` 第 6 节冲突时以本文为准。
> 日期：2026-08-20
> 色值来源：**从高德地图瓦片逐像素统计得出**，不是估的。取样 `style=7` 标准图，广州荔湾/海珠 z15–z16 共四张 512×512 瓦片。

## 0. 两条推翻

**推翻「深色大屏」。** 全产品走浅色，一套色板，没有第二套主题。之前 PRD 里所有深色描述作废。

**推翻「路况铺满全图」。** 高德默认地图**根本不显示路况**——实测四张瓦片里没有任何绿黄红路段。路况是一个**可开关的叠加图层**，不是底图的一部分，而且只叠在主干道上。

## 1. 高德实测色板

按在瓦片中的出现频率排序。这是底图的全部颜色，不多也不少。

| 色值 | 占比 | 用途 | 说明 |
|---|---|---|---|
| `#FCF9F2` | 25.2% | **陆地底色** | 暖白偏黄。不是冷灰，不是纯白 |
| `#ADD2FF` | 20.4% | 水系 | 明亮的蓝，不压暗 |
| `#CFE8A7` | 13.4% | 绿地 / 公园 | 黄绿 |
| `#FFFFFF` | 11.4% | **普通道路路面** | 纯白，**比陆地底色亮** |
| `#EEECE7` | 4.2% | 建筑 / 街区块 | 几乎和底色一样 |
| `#A3CCFF` | 3.8% | 水系次级 | 岸线或深水 |
| `#F1CF5F` | 3.4% | **主干道 / 快速路** | **金黄，高德的招牌** |
| `#C8E49D` | 3.1% | 绿地次级 | |
| `#DED8CD` | 2.5% | **道路 casing** | **暖灰，不是深色** |
| `#F6E3A3` | 0.9% | 次一级黄路 | 比主干道浅 |
| `#E9E0ED` | 0.7% | 特殊用地 | 淡紫，商业/机场类 |
| `#BF506A` | 0.3% | 高速公路 | 暗红 |
| `#E1AD04` | 0.25% | 黄路的 casing | 深金 |

### 1.1 四条结构规律

看色板不如看规律。这四条比色值本身重要：

1. **整体暖调。** 底色 `#FCF9F2` 偏黄。任何冷灰、蓝灰、深色都会立刻破坏高德感。
2. **路比地亮。** 白路 `#FFFFFF` 压在暖白地 `#FCF9F2` 上，对比只有约 3%。极度克制。
3. **金黄主干道是唯一的高饱和元素。** 一眼认出高德靠的就是它。整张图只有它跳出来。
4. **建筑极度克制。** `#EEECE7` 和底色差 4%，几乎不可见。建筑是背景不是主角。

## 2. 道路怎么画

### 2.1 每条路两层

```
先画 casing   更宽，暖灰或深金
后画 fill     更窄，白或金黄
```

只有一层线条就会像电路板不像地图。casing 是"路面感"的唯一来源。

### 2.2 分级表

| OSM `highway` | casing | fill | z15 fill 宽 | z17 fill 宽 |
|---|---|---|---|---|
| `motorway` | `#A03D52` | `#BF506A` | 7 | 14 |
| `trunk` / `primary` | `#E1AD04` | `#F1CF5F` | 6 | 12 |
| `secondary` | `#E1AD04` | `#F6E3A3` | 4.5 | 9 |
| `tertiary` | `#DED8CD` | `#FFFFFF` | 3.5 | 7 |
| `residential` | `#DED8CD` | `#FFFFFF` | 2.5 | 5 |
| `service` / `living_street` | 无 casing | `#FFFFFF` | 1.5 | 3 |
| `footway` / `path` | 无 casing | `#DED8CD` 虚线 | 1 | 2 |

casing 宽度 = fill 宽度 + 2。宽度用 `interpolate` 表达式随 zoom 连续变化，**不要固定值**。

### 2.3 面状要素

| 要素 | fill |
|---|---|
| 陆地（底） | `#FCF9F2` |
| 水系 | `#ADD2FF` |
| 绿地 / 公园 | `#CFE8A7` |
| 建筑 | `#EEECE7`，描边 `#DED8CD` |
| 特殊用地 | `#E9E0ED` |

## 3. 路况是可开关的叠加层

**默认关闭。** 高德标准图不显示路况，我们也不默认显示。

打开后的规则：

- **只叠 `motorway` / `trunk` / `primary` / `secondary`**。`tertiary` 及以下永远保持白色，不参与
- 叠加方式是在该路的 fill 层**之上**再画一条同宽的线，不是改 fill 的颜色

四档颜色（这四个是我按浅底可读性定的，**不是从瓦片测出来的**，因为标准图里没有路况）：

| 档 | 色值 |
|---|---|
| 畅通 | `#2FA84F` |
| 缓行 | `#F2A93B` |
| 拥堵 | `#E0483D` |
| 严重拥堵 | `#9B2C24` |

**路况数据是模拟的，图例上必须标。**

## 4. 建筑挤出

高德标准图是平面的。我们要 2.5D，所以这部分没有高德参照，按下面做：

| 项 | 值 |
|---|---|
| `fill-extrusion-color` | `#E8E4DC` |
| `fill-extrusion-height` | `levels × 3` |
| `fill-extrusion-opacity` | `0.92` |
| `fill-extrusion-vertical-gradient` | `true`（浅底上需要它给体积感，跟深色那版相反） |

**层数估算的 597 栋要区分**：`levels_estimated === true` 的用 `#EFEBE3`（更浅）+ `opacity 0.72`。真实层数的用上表的实色。这是数据诚信要求，不是可选项。

图例里标：`建筑层数公开 544 栋 / 估算 597 栋（52%）`。

---

## 5. 我们的叠加层怎么在暖白底上站住

底图极度克制，是为了让**我们自己的东西**跳出来。这是分工：高德底图负责"这是哪"，我们的图层负责"发生了什么"。

沿用 `docs/design/主看板定稿-规格.md` 那套语义色，它们在 `#FCF9F2` 上都成立：

| 用途 | 色值 | 注意 |
|---|---|---|
| 火情 / 告警 | `#E5484D` | |
| 方案 A / 可行 | `#30A46C` | 和绿地 `#CFE8A7` 差得够远，不会混 |
| 方案 B / 主色 | `#5B5BD6` | |
| 医疗到场路线 | `#0E9AA7` | |
| 水源 | `#3B82F6` | 和水系 `#ADD2FF` 差得够远 |

### 5.1 一条冲突要避开

**方案路线不要用黄色系。** `#F1CF5F` 已经被主干道占了，任何接近的黄都会跟底图打架。

### 5.2 叠加层要有描边

暖白底上细线容易糊。方案路线、车流轨迹这类叠加线，**加 1px 白色外描边**再画主色，让它从底图上"浮"起来。

## 6. 镜头

| 项 | 值 |
|---|---|
| 中心 | `[113.253289, 23.113914]` 广州民间金融大厦 |
| zoom | `15.5` |
| pitch | `55` |
| bearing | `-20` |

**默认视角要能看清路面、看清楼、看清路口。** 上一版默认在看整个荔湾+海珠区，那个高度上高德自己也只是一片灰白细线。尺度错了，颜色再准也没用。

## 7. 外壳（顶栏 / 侧栏 / 数据卡 / 告警流）

全部浅色，跟地图同一套。

沿用 `主看板定稿-规格.md` 的：页面底 `#F4F5FA`、卡片 `#FFFFFF`、描边 `#E8EAF0`、主色 `#5B5BD6`、正文 `#1A1D26`、次要 `#6B7280`、三级 `#9CA3AF`。圆角卡片 12 / 控件 8 / 标签 4。阴影 `0 1px 3px rgb(16 24 40 / .06)`，不用重投影。

页面底 `#F4F5FA` 略偏冷，地图底 `#FCF9F2` 偏暖，两者相邻时会有轻微色温差。**这是可接受的**——外壳和地图本来就该有分界。不要为了统一把地图底改冷，那会丢掉高德感。

---

## 8. 验收

改完把截图和高德夜间/日间标准图并排比。三条判断：

1. **主干道一眼能认出来**（金黄），支路是白的不是彩的
2. **整体偏暖**，没有冷灰或深色块
3. **克制**——建筑几乎看不见，路况默认不显示，画面上最跳的应该是我们自己的事件和方案图层

第 3 条最容易做砸。上一版失败就是因为底图抢戏抢到把主角埋了。
